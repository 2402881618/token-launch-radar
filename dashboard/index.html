ProtocolTVLWhy it is set aside

Each of these records no token, yet none is a launch of its own: a staked or wrapped form of a token that already trades, a bridge, a versioned pool, or an exchange's product. Saying otherwise would be the radar inventing launches.

The formula

implied = TVL × category multiple × growth × maturity

  • Category multiple — the median market-cap / TVL of the live-token protocols in the same category, with each peer's ratio capped at 2.0 and the median shrunk toward the global median (four prior observations), then clamped to 0.05–0.80. A category with fewer than three live peers takes the global median, so no single protocol can set a whole category's multiple.
  • Growth — 1 + clamp(7-day TVL change, −60%, +120%) / 100 × 0.5.
  • Maturity — 0.55 + 0.45 × √(min(age, 3 years) / 3 years). It rises fast in the first year and then saturates; an unknown age counts as one year.
  • Rank — the whole board is sorted by implied value, strongest first. No protocol name is ever special-cased.
